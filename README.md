# Hoja de Trabajo 2: Procesos de Decisión de Markov (MDPs)

Este proyecto implementa desde cero la solución al problema "Frozen Lake" utilizando Procesos de Decisión de Markov y el algoritmo de Value Iteration.

En el Task 2.1 se modela el entorno Frozen Lake como un MDP completo, definiendo estados, acciones, función de transición estocástica (hielo resbaladizo) y función de recompensa.

En el Task 2.2 se implementa el algoritmo Value Iteration basado en la Ecuación de Bellman para encontrar la política óptima que maximiza la utilidad esperada del agente, considerando un factor de descuento de 0.9.

Todas las implementaciones usan únicamente NumPy, Pandas y Matplotlib.
